# Task Tracker

A small task tracker: a SQLite store with a JSON HTTP API and a command-line interface. Standard library only. Run it from a checkout with `PYTHONPATH=src`; it is not packaged for installation.

This is the worked example for the Agent Playbook. It is a realistic target repository, not part of the playbook itself.

## Run

```sh
PYTHONPATH=src python3 -m tracker.cli --db tracker.db add "Write docs"
PYTHONPATH=src python3 -m tracker.cli --db tracker.db list
PYTHONPATH=src python3 -m tracker.api   # serves on http://127.0.0.1:8000
```

## Test

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -t .
```

- [`docs/agent/project-map.md`](docs/agent/project-map.md) — verified structure, contracts, and commands.

Bootstrap would also create the three workflow skills in `.agents/skills/` and `.claude/skills/`. They are omitted here because they are identical to the playbook's `skills/` directory and would be picked up while working on the playbook itself.
